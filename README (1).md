# راهنمای فارسی CS50P

راهنمای آموزشی راست‌چین برای یادگیری Python و حل مرحله‌ای Problem Setهای CS50P.

## روش استفاده
1. مفاهیم هر هفته را بخوان.
2. تمرین‌های کوچک را حل کن.
3. راهنمای Problem Set را مطالعه کن.
4. کد خودت را بنویس و برای بررسی ارسال کن.
5. پس از اصلاح، نسخه نهایی را در بخش مرور ثبت کن.
